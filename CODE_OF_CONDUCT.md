# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and welcoming. Disagree about code, not about people.
- No harassment, insults, discriminatory jokes, or sharing someone's private information.
- Give and accept constructive feedback gracefully.
- Focus on what's best for the project and its users.

## Scope
This applies in issues, pull requests, discussions, and anywhere you represent the project.

## Reporting
If someone's behaviour is a problem, contact the maintainer
([@SakshiGaikwad05](https://github.com/SakshiGaikwad05)) privately, using the email on their GitHub profile.
Reports are kept confidential. The maintainer may edit or remove comments, close threads, or block
contributors who break these rules.
